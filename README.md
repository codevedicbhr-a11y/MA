# Mary's Academy – One Page Website

**Complete English Medium School** | Hanuman Chowk, Sarhad, Madhubani, Bihar

## What's New
- **Single page** website (all sections on one scrollable page)
- **Hero image carousel** with 6 high-quality campus photos
- **Fresh colour palette**: Deep Teal + Warm Coral/Orange
- **Principal photo**: Placeholder (dummy) – easy to replace later
- WhatsApp floating button
- Enquiry form popup on first load
- Contact form + Google Map
- SEO ready (meta, sitemap, robots)

## How to replace Principal photo
1. Put your photo in `images/` folder (e.g. `principal.jpg`)
2. In `index.html` find the Principal card
3. Replace the `<div class="leader-placeholder">...</div>` with:
   `<img src="images/principal.jpg" alt="Anuradha Kumari - Principal" loading="lazy">`

## Deploy
Upload the entire `marys-academy` folder to any hosting.
